# Mihin Mennään

**Mihin Mennään** is a family-friendly web app that helps parents discover places and activities to do with kids — parks, playgrounds, cafés, indoor play areas, and more.

**Live demo:** https://mihin-mennaan-webapp2.web.app/

## Features
- Curated ideas for family outings
- Simple and clean UI for quick planning
- Works great on mobile

## Tech Stack
- Vue 3
- Vuetify 3
- Vite
- Firebase Hosting

## Getting Started

### Install
```bash
npm install

Run locally:
npm run dev

Build:
npm run build
Preview build
npm run preview

Deployment:
This project can be deployed with Firebase Hosting.

firebase deploy
